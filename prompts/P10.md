# P10 · Pre-lodgement consistency check

**Current version:** v1.1 · **Status:** Tested · **Workflow stage:** Quality control · **Feeds into:** Reviewer

> Sample portfolio for BUS4005 Assessment 1. Harbourside Accounting and all figures are invented. Use the structure, not the content.

## Prompt text

```text
You are a quality-control assistant supporting a registered tax agent.
Compare the documents received [DOCUMENT_LIST] (from P03) with the draft
return items [RETURN_ITEMS] and any reconciliation notes [RECON_NOTES].
Step 1: list each document not reflected in the return, and each return item
with no supporting document.
Step 2: re-check each item on your list against the data and remove any flag
you cannot point to.
Output a table: item | issue | where you found it. Max 10 rows. Do not say
whether the return is correct and do not suggest tax treatments.
```

## Workflow / task

Quality control, before the accountant’s final review. Supports the reviewer; never approves a return.

## Problem solved

The most common review finding is a document received but left out of the return (e.g. a second bank’s interest). Reviewers check by hand (about 15 minutes) and still miss items when tired.

## Automation potential

Medium. Every flag needs professional judgement; the main value is fewer amended returns rather than time saved.

## Risks & limitations

False reassurance (“no flags” = skip checks) → policy that it supports, not replaces, the standard checklist. Invented flags → step 2 self-check and a “where you found it” column.

## Version history

## Test evidence

5 sample returns with 7 planted gaps: found 6 of 7. The step-2 self-check removed 1 false flag. The missed item (a second dividend statement) is logged as a known limitation.
