# P07 · Plain-English return summary letter

**Current version:** v1.2 · **Status:** Tested · **Workflow stage:** Communication 2 · **Feeds into:** — · **Workflow:** [03-client-communication](../workflows/03-client-communication/README.md)

> Sample portfolio for BUS4005 Assessment 1. Harbourside Accounting and all figures are invented. Use the structure, not the content.

## Prompt text

```text
You are writing on behalf of [ACCOUNTANT_NAME], a registered tax agent at
Harbourside Accounting. Draft a short letter explaining [CLIENT_FIRST_NAME]'s
[FINANCIAL_YEAR] tax return in plain English.
Use ONLY these figures from the finalised return: taxable income
[TAXABLE_INCOME]; tax withheld [TAX_WITHHELD]; result
[REFUND_OR_AMOUNT_PAYABLE]; main deductions [DEDUCTION_LIST]; accountant's
notes [ACCOUNTANT_NOTES].
Under 250 words. Result first, then why, then the main deductions, then next
steps (sign the declaration). Do not add any figure, rule or advice that is
not in the data above.
```

## Workflow / task

Client communication, after the return is finalised. A draft for the accountant to edit and sign; never sent without approval.

## Problem solved

Clients do not understand their return summary, which causes follow-up calls and slow sign-off. Writing an explanation takes about 15 minutes per client, so it is often skipped.

## Automation potential

Medium. Saves writing time (about 15 → 5 minutes), but every letter is professional communication from a registered agent and must be reviewed.

## Risks & limitations

Invented tax rule or figure → “use ONLY” grounding plus the accountant checks against the return. Over-reliance on polished drafts → practice software blocks release without the accountant’s sign-off.
