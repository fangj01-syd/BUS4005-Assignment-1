# P09 · Weekly workload report for the partner

**Current version:** v1.1 · **Status:** Logic-tested · **Workflow stage:** Practice management · **Feeds into:** —

> Sample portfolio for BUS4005 Assessment 1. Harbourside Accounting and all figures are invented. Use the structure, not the content.

## Prompt text

```text
You are the practice manager at Harbourside Accounting, reporting to the
managing partner. Write this week's workload summary from the job tracker
export [JOB_TRACKER_CSV] (client, job type, staff, status, days in status) and
last week's summary [LAST_WEEK_SUMMARY].
Use ONLY the data provided. Max 200 words plus one table:
1. Returns lodged, waiting on clients, waiting on review
2. Table of jobs in progress per staff member
3. Bottlenecks: any job in the same status for more than 10 days
4. One change compared with last week
Do not comment on individual staff performance.
```

## Workflow / task

Practice management. Runs every Friday after the tracker export; the practice manager checks the numbers and forwards it for the Monday meeting.

## Problem solved

The partner has no quick view of where work is stuck. The manual report takes about 1.5 hours, so it is skipped in the busiest weeks — exactly when it is needed.

## Automation potential

High. Structured input, same format every week; a 10-minute check of the headline numbers.

## Risks & limitations

Counting errors → headline numbers checked against the tracker totals. Report used to judge staff unfairly → workload shown as counts only, no performance comments.
