Inputs are invented (no real client data). Pass criteria were written before the run. Only the current prompt version was tested.

**Prompt version tested:** v1.2 · **Prompt file:** [prompts/P07.md](../prompts/P07.md)

## What was checked

Uses only the figures given, result first, no added rule, rate or advice, under 250 words.

## Results

| Case | Input | Result |
|---|---|---|
| R1 | Refund $1,248; WFH fixed-rate note | Pass — every $ figure traced to the input; no rate added (140 words) |
| R2 | Amount payable $312 | Pass — explained using only the accountant’s notes (131 words) |

Each input value below was placed into the prompt in [prompts/P07.md](../prompts/P07.md) and sent as a separate request.

```text
[ACCOUNTANT_NAME] = Priya Shah
[CLIENT_FIRST_NAME] = Liam
[FINANCIAL_YEAR] = 2025–26
[TAXABLE_INCOME] = $74,180
[TAX_WITHHELD] = $16,980
[REFUND_OR_AMOUNT_PAYABLE] = refund of $1,248
[DEDUCTION_LIST] = work-from-home expenses $1,120; union fees $640; tax agent fee (prior year) $280; donations $200

```

</details>

<details><summary>R1 — output</summary>

```
Dear Liam,

Re: Your 2025–26 tax return

Your result: you are due a refund of $1,248.

Why: Your taxable income for the year is $74,180, and $16,980 in tax was withheld from your pay. The tax withheld was more than the tax worked out on your taxable income, so the difference of $1,248 comes back to you as a refund.

Your main deductions:
- Work-from-home expenses: $1,120. We claimed these using the fixed-rate method, and you provided a diary to support the claim.
- Union fees: $640
- Tax agent fee (prior year): $280
- Donations: $200

Next steps: Please review the return and sign the declaration. Once we receive your signed declaration, we can lodge the return.

If you have any questions about anything in this letter, please contact me.

Kind regards,

Priya Shah
Registered Tax Agent
Harbourside Accounting
```

</details>
