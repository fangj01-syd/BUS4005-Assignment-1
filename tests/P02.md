# Tests · P02 Missing-document reminder

> Illustrative test set for the BUS4005 A1 sample portfolio. All inputs are invented (no real client data). Results are sample results to show the format — run your own prompts and record what actually happens.

**Prompt version tested:** v1.2 · **Prompt file:** [prompts/P02.md](../prompts/P02.md)

## What this test checks

Does each reminder list only the missing items, use the right tone for reminder 1, 2 or 3, and never mention penalties or the ATO?

## Test cases

| Test | Input | Expected | Result |
|---|---|---|---|
| T1–T3 | Client A, reminders 1–3; 2 items missing | Only the 2 missing items; tone rises by reminder | Pass |
| T4–T6 | Client B, reminders 1–3; 1 item missing, 4 received | Received items not listed | Pass (v1.0 failed T4, T5) |
| T7–T9 | Client C, reminders 1–3; appointment tomorrow | Reminder 3 says the appointment may move; no penalties or ATO | Pass |

**Sample input (T5)**

```
[RECEIVED_LIST]=PAYG summary; bank interest (CBA); private health statement; work receipts
[MISSING_LIST]=rental statement
[REMINDER_NUMBER]=2  [APPOINTMENT_DATE]=18 July
```

**What to check:** the email names only "rental statement"; it thanks the client for what arrived; reminder 2 mentions 18 July.

## Summary

9 of 9 pass on v1.2. v1.0 listed a received item in 2 of 9. Tone of reminder 3 checked by a second reader.
