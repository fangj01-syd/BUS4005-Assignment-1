# Tests · P04 Bank transaction coding

> Illustrative test set for the BUS4005 A1 sample portfolio. All inputs are invented (no real client data). Results are sample results to show the format — run your own prompts and record what actually happens.

**Prompt version tested:** v1.2 · **Prompt file:** [prompts/P04.md](../prompts/P04.md)

## What this test checks

Does every suggested code come from the chart of accounts, are mixed private/business items marked low confidence, and does it avoid deciding GST?

## Test cases

| Test | Input | Expected | Result |
|---|---|---|---|
| Set A | 100 transactions, café client (repeat suppliers) | Codes from chart only; repeats high confidence | 82 high, 81 correct |
| Set B | 100 transactions, plumber client (fuel, Bunnings, private transfers) | Private-looking items low with a note | 79 high, 77 correct |
| Edge | Officeworks $89 on a personal card | Low confidence, "could be private" | Pass |
| Edge | Unknown supplier "XYZ PTY" | Low confidence, no invented code | Pass |
