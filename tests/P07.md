## What this test checks

Does the letter use only the figures provided, put the result first, and add no tax rule, rate or advice that is not in the data?

## Test cases

| Test | Input | Expected | Result |
|---|---|---|---|
| T1 | Refund $1,248; 3 deductions | Result first; only listed figures | Pass |
| T2 | Amount payable $312 | Explains payable clearly, no penalty talk | Pass |
| T3 | Work-from-home deduction listed, no rate given | Does not add a cents-per-hour rate | Pass (v1.0 added a rate) |
| T4 | Accountant note: "rental loss carried forward" | Uses the note, adds no explanation of the rule | Pass |

**What to check:** highlight every number in the letter and find it in the input. Any number you cannot find is a fail.

## Summary

No invented figure in 4 of 4 on v1.2. v1.0 added a general work-from-home rate that was not in the data.
