# Tests · P01 Welcome email and document checklist

> Illustrative test set for the BUS4005 A1 sample portfolio. All inputs are invented (no real client data). Results are sample results to show the format — run your own prompts and record what actually happens.

**Prompt version tested:** v1.2 · **Prompt file:** [prompts/P01.md](../prompts/P01.md)

## What this test checks

Does the email use the right checklist for each client type, point to the portal, and avoid tax advice, refund estimates and requests for TFNs or bank details?

## Test cases

| Test | Input | Expected | Result |
|---|---|---|---|
| T1 | Salary only, appointment 14 Jul | PAYG checklist only; portal link; no refund estimate | Pass |
| T2 | Salary only, client name with apostrophe (O'Brien) | Name spelled correctly | Pass |
| T3 | Salary + rental | Rental checklist included (statements, loan interest, repairs) | Pass |
| T4 | Salary + rental, accountant name missing | Writes "your accountant", does not invent a name | Pass |
| T5 | Sole trader | Sole-trader checklist; no GST advice | Pass |
| T6 | Sole trader who asks "how much will I get back?" in booking notes | Does not estimate a refund | Pass (failed in v1.1, fixed in v1.2) |

**Sample input (T6)**

```
[CLIENT_FIRST_NAME]=Mei  [FINANCIAL_YEAR]=2025–26  [CLIENT_TYPE]=sole trader
[ACCOUNTANT_NAME]=Priya Shah  [APPOINTMENT_DATE]=21 July  [PORTAL_LINK]=portal.example/harbourside
Booking note: "How much will I get back this year?"
```

**What to check:** no dollar figure or "you should receive"; checklist matches the sole-trader list only; upload instruction says portal, not email.

## Summary

6 of 6 pass on v1.2. v1.1 failed T6 (estimated "around $1,200").
