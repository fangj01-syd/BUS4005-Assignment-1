Inputs are invented (no real client data). Pass criteria were written before the run. Only the current prompt version was tested.

Right checklist for each client type, portal link, appointment date and accountant, no refund estimate or tax advice, no request for TFN or bank details by email, under 200 words.

## Summary

**6 of 6 pass.** Finding: when data was missing (T4, T6) the model added a note to staff above the email. That is safe for a human-checked draft, but if this ever sends automatically the note would reach the client. **Next version:** add “If any input is missing or unusual, output only NEEDS REVIEW: <reason>.”
